# 视频换人 prompt 模板

来源：AI 综艺工作室 `sd2fast_edit` 系列（10+ 条自审通过，相关 0.64–0.76、零延迟），加上 2026-10-21 拆解的即梦爆款提示词（抖音「秋刀雨」神之八秒复刻，Seedance 2.5 全能参考）。

验证（2026-10-21，seedance-2-0-fast 4s 480p，同一参考图、同一原片切片，只换 prompt）：旧英文长描述 prompt r=0.80，本模板 r=0.84，均 lag −1 帧、无残留。样本 1 条，证据在粥粥工坊 `内容生成结果/20261021_v2v-template-probe/`。

## 模板

`{}` 是填空；不换背景时删掉场景图那半句，场景行用前一个选项。

```
将 @图片1 定义为角色（脸、发型、体型、服装）{，将 @图片2 定义为场景}。
严格编辑 @视频1：只把舞者替换成 @图片1 的角色，其余全部不变。
继承：舞蹈编排、动作幅度与节拍、站位、朝向、机位、景别、运镜和镜头节奏逐帧跟随 @视频1，不更剧烈也不更安静。
身份：外貌、发型、身材、气质、服装只按 @图片1，全程一致；@图片1 只决定长什么样，不决定怎么动。{≤1 句：上一条出片里漂掉的细节}
清除：原舞者的{帽子 / 口罩 / 服装 / 发型}和脸一处都不保留。
场景：{保持 @视频1 的场景 | 背景全部换成 @图片2}；全程只有一个人，没有镜中倒影。
画面：{画风}，动作流畅，运镜稳定，节奏卡点准确。
禁止：文字、字幕、歌词、水印、标志、马赛克{、脸部遮挡}；第二个人、分身。
重申：只把 @视频1 的舞者替换为 @图片1，动作、节奏、运镜 1:1 复刻。
```

多人原片：「舞者」改成「左边 / 中间 / 右边的舞者」，每个位置一张角色图，按位置一一对应；仍然只换要换的人。

角色图是三视图时，身份行末尾加一句：「正面视图锁脸和服装正面，侧面、背面视图管转身和背对镜头时的发型与服装。」（来自 Home `/replace-video-character`）。出现分身时改传单视图。

## 每行的作用

| 行 | 作用 | 依据 |
|---|---|---|
| 定义 | 每份素材只管一件事，模型不用猜哪张图管什么 | 即梦爆款提示词；AI 综艺 dnc1–dnc9 |
| 严格编辑 | 把任务定成「编辑」，不是「参考着重新生成」 | AI 综艺 dnc1 |
| 继承 | 逐项点名要保留的维度；「不更剧烈也不更安静」压住幅度漂移 | AI 综艺 dnc2 |
| 身份 | 外观交给图，文字不重复描述；「只决定长什么样」切断参考图把姿态往回拉 | 粥粥工坊 H3 三个 take 腿被钉在关键帧站姿 |
| 清除 | 点名原舞者最显眼的特征，防止残留 | 粥粥工坊试点、AI 综艺 dnc1 |
| 场景 | 换背景时说清旧背景全部替换；单人片写「只有一个人、没有倒影」 | AI 综艺 dnc2（镜面墙出倒影后补） |
| 画面 | 画风一句，跟角色图一致 | — |
| 禁止 | 只列原片里真会出现的东西（歌词、水印、口罩遮脸） | 即梦爆款提示词「不要有遮挡」 |
| 重申 | 结尾再说一遍换人，防止后段注意力衰减 | 即梦爆款提示词把换人指令说了两遍 |

## 出了问题改哪一行

| 现象 | 改 |
|---|---|
| 原舞者回来了 / 只换了一半 | 删减其他行，prompt 越长换人指令越弱（粥粥工坊 nawa v2：加 CAMERA LOCK 约束块后整段回到原班人马）；清除行补上漏掉的特征 |
| 身份某处漂移（鞋、徽章、发色） | 身份行末尾加一句只写这一处，例如「黑色皮鞋，不是白色球鞋」 |
| 动作幅度变小、站桩 | 检查参考图是不是姿态很强的全身站姿；换成三视图或中性站姿 |
| 出现第二个人或倒影 | 场景行写清墙面材质（哑光实心墙，不是镜子、不是玻璃） |
| 推镜 / 新增景别 | 继承行里「机位、景别、运镜」保持原样，不另加约束块 |
| 文字、歌词残留 | 先回第 2 步处理切片，prompt 只是补充 |
